# 着せ替え素材の点検結果(Claude、2026-11-19)

元の ZIP(Minato-Claude-Review.zip)を別のフォルダに展開して点検しました。
このフォルダは、直した所を反映した版です。

## 直したこと

| 何を | どう直したか | 対象 |
|---|---|---|
| 艇外装の面積0の三角形 | 各4枚を取り除いた。見た目・UV・色・材質は同じ。`Catalog.csv` の三角形数も合わせた(例 3561 → 3557) | Hull 30点 |
| ヘルメットの「目元を見せる」オン・オフ(追加) | シールド(材質 Smoked shield)を別の部品 `Visor` に分けた。部品の原点は横の丸い金具(蝶番、ヘルメットの座標で x 0.022・y 0.006)。<br>オフ(下ろす)は元と同じ見た目。オン(上げる)は `Visor` を z 軸で 45° 回し、蝶番を中心に 1.1 倍にする。<br>値はノードの `extras.visorUp` に書き、同じ動きを glTF のアニメーション `VisorUp`(0.25秒)にも入れた | Helmet 30点 |

- 30点とも殻とシールドの形が同じ(色・模様・飾りだけ違う)ため、同じ蝶番・角度・倍率で全部に効きます。
- 殻にはもともと目元の穴があり、シールドを上げると中が見えます。ゲームでは中にアバターの頭を出します。
- 上げた時、SSR・UR の頭頂の飾り(銀架・淡金環・赤金翼など)とは、少し重なって見える所があります。形が壊れて見える所はありません。
- モーターカバー・ステアリング・艇首旗・`Plates.glb` は変えていません。

## 実測で確認

確かめ方: Python で GLB を1つずつ読み、数を数えて比べました。見え方は、ブラウザ版と同じ three.js(0.170)で、ゲームの艇(boat.glb)に部品を付けて描きました。

1. **カタログ**
   - `Catalog.csv` は150行で、GLB 150個と1対1で合います。共通の `Plates.glb` はカタログに入っていません(抽選の対象外)。
   - 5種類×30点です。どの種類も N/R/SR/SSR/UR が 8/8/7/4/3 点です。
   - ID・ファイル名・フォルダ・レア度は互いに合っています。同じ番号の意匠名は、5種類で同じです。中身がまったく同じファイルはありません。
2. **確率**
   - 単品の確率は 6.25 / 3.75 / 2 / 1.125 / 0.5% で、排出率 50 / 30 / 14 / 4.5 / 1.5%(合計100%)を各レア度の点数で割った値と合います。
   - 1〜10000 の割り当て幅は 5000 / 3000 / 1400 / 450 / 150 で、排出率と合います。
   - 「何回で出会えるか」の表9つ、100回でURなしの約22%、全150点を混ぜた時の特定UR 0.1% も、計算し直して一致しました。
3. **GLB の中身**
   - 全151個が正しい glTF 2.0 です(長さ・番号の範囲・数値の異常・法線・UV 0〜1・min/max)。
   - 三角形の数はカタログと一致します(艇外装の面積0の三角形は直しました)。
   - 画像は各1枚、960×512 の PNG です。
4. **金の材質**
   - UR 全15点に `Polished gold`(金属度 0.96・粗さ 0.21)があります。
   - UR 以外には金がありません。
5. **共通部品 Plates.glb**
   - 三角形4枚で、左右の側面の板だけです(x −1.11〜−0.83、z ±0.45〜0.51)。船首の板はありません。
   - 旧 Plates と入れ替えると、艇番1〜6の数字が左右どちらからも正しい向きで読めます(鏡写しになりません)。
   - 上から見ても、船首に白い四角は出ません。
6. **組み付けと動き**
   - 代表艇(01・28・29・30)に5部品を付けて、ゲームと同じ式で動かしました(ハンドル ±1、モーター旋回、ターンの体重移動)。
   - ハンドル・モーターカバー・ヘルメットは、それぞれの動く組と一緒に動きます。ヘルメットは元のヘルメットと同じ位置・大きさに収まります。
7. **旗の色**
   - 布(`Lane fabric`)に艇番の色を付けると、模様を残したまま色が変わります。
8. **旧 Cowl との重なり**
   - 新しい艇外装は旧 Cowl の部分も覆います。旧 Cowl を残しても、はみ出しは見えませんでした。

## 見本画像で確認

- 装着見本の4艇(白艇・黒漆・象牙・濃藍)について、黒漆・象牙・濃藍の色と金の縁は、見本 `Equipped.jpg` と同じ見え方でした。
- 艇番は白い板に黒い数字で、はっきり読めます。
- 艇番2(黒の板)は、黒漆(28)の艇では地の色と近くなります。ただし白い枠があるので読めます。

## 未確認

- Roblox Studio への取り込み(資産の登録はこの依頼の対象外です)。Roblox の照明での色、旗のはためきも未確認です。
- ゲームに組み込む時に注意すること(問題ではなく、別の作業で直す所):
  - **旗のはためき:** ブラウザ版は、旗の中の最初の1つの形だけを揺らします。新しい旗は3つの材質に分かれているので、布(`Lane fabric`)を揺らすように変える必要があります。
  - **塗装の色替え:** 今のゲームは、部品の材質名(HullWhite・Trim など)で色を替えます。新しい部品は色が画像に焼き込まれているので、そのままでは色替えが効きません(品ごとに見た目が決まっている前提なら問題ありません)。
