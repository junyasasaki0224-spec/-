# 大手ゲームサイトへの出し方（オーナー向けガイド）

## 1. しくみ（ひとことで）

自分のサイトは「試す場所」、大手サイトは「当たった作品を大勢に届けて稼ぐ場所」です。

- 毎日のゲームは、まず自分のサイトに出す。
- 数字が良かった作品だけを、英語版にして大手サイトに出す。
- 大手サイトの広告収入は、そのサイトと分け合う。

## 2. どの作品を出すか（判断ルール）

`research/performance.json` の数字で判断します。日曜の週次レビューでAIが候補を挙げます。

| 条件 | 出し先 |
|---|---|
| 自サイトで「当たり」（月3,000PV以上 または 平均プレイ3分以上かつ再訪率15%以上） | **CrazyGames** に提出 |
| CrazyGames の本公開で収益が出た／Poki から声がかかった | **Poki**（独占契約）を検討。自サイトからは外す必要がある |
| それ以外 | 自サイトだけに置いておく（検索の入口として残す） |

計測を入れる前の最初の1〜2本は、練習として CrazyGames に出してみて構いません（手順を覚えるため）。

## 3. 提出用パッケージの受け取り方（AIが毎回自動で作っている）

すべてのゲームについて、英語版・各サイトの広告の仕組みを組み込んだ版が、自動で作られています。

1. GitHub のリポジトリを開く → 上の **Actions** タブ。
2. 一番上（最新）の **CI** の実行結果を開く。
3. 下のほうの **Artifacts** から `portal-packages` をダウンロードして解凍する。
4. 中身：
   - `crazygames/<ゲーム名>.zip` … アップロードするファイル
   - `crazygames/<ゲーム名>-landscape.png` / `-portrait.png` … 画面写真
   - `crazygames/<ゲーム名>-SUBMISSION.md` … **投稿フォームに貼る英語の文章と手順**
   - `poki/...` … Poki 用（中身は同じ構成）

## 4. CrazyGames に出す手順

1. CrazyGames の開発者ページ（https://developer.crazygames.com/）で開発者アカウントを作る。
   - 収益を受け取るには、本名・住所・支払い先などの登録が必要。**ここはAIにはできないので、あなたが行う。**
   - 支払いは月1回、残高が€100を超えたら（二次情報による。最新の規約を確認すること）。
2. 「新しいゲームを追加」から、`<ゲーム名>.zip` をアップロードする。
3. `SUBMISSION.md` の英語の文章を、タイトル・説明・遊び方・カテゴリ・タグの欄にコピーして貼る。
4. 画面写真をアップロードする。サイトが別のサイズを指定していたら、AIに「〇〇×〇〇の画像を作って」と頼む。
5. 審査を待つ（数日）。結果は下の「記録」に書く。
   - 通れば、まずお試し公開（Basic Launch）になる。
   - 数字が良ければ本公開（Full Launch）と収益化に招待される。
6. 落ちた場合は、理由をAIに伝えて直してもらう。

## 5. 注意点
- **Poki は原則Web独占**です。出すと、自分のサイトを含む他のWebサイトには置けなくなります。本当に当たった作品だけにします。
- 審査では「よくあるゲームの真似・素材の差し替えだけ（clone / reskin）」は落とされます。独自の工夫（twist）が説明文で伝わるようにしてあります。
- 収益分配・独占・技術要件は変わることがあるので、提出前に各サイトの最新の規約を読んでください。
