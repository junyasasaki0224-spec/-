# ターフジョッキー — 3D競馬ジョッキーシミュレーション

騎手になって手綱を取る、技術勝負の3D競馬ゲームです。ブラウザだけで動作し、ビルドもインストールも不要です。
(馬名・騎手名・レース名はすべて架空です。コースの諸元は実在の競馬場を参考にしています)

## 遊び方

```bash
npm start          # = python3 -m http.server 8080
# → http://localhost:8080 を開く
```

ES Modules を使っているため、`index.html` を直接開くのではなく HTTP サーバー経由で開いてください
(GitHub Pages などの静的ホスティングにそのまま置けます)。

| 操作 | キーボード | タッチ |
|---|---|---|
| 追う(加速) / 離すと「持ったまま」 | ↑ / W | 追う |
| 抑える | ↓ / S | 抑える |
| 進路を左右へ | ← → / A D | ◀ ▶ |
| スタート(ゲートが開いた瞬間) / ムチ | SPACE | ムチ |
| 手前替え(直線入口) | SHIFT / E | 手前 |
| 視点切替 / 一時停止 | C / P | 画面右上 |

## 再現している駆け引き

- **スタミナとペース配分** — 有酸素速度を超えた分だけ加速度的に消耗。前半の貯金は直線の失速で倍返しになる。使い切ると時間とともにさらに脚が止まる
- **折り合い** — 気性の激しい馬は序盤・スローペース・下り坂・1周目スタンド前の歓声で掛かる。前に馬を置く(壁を作る)と落ち着く
- **スリップストリーム** — 他馬の真後ろで風の抵抗を軽減。向かい風の日ほど効く。ただし「前が壁」のリスクと表裏一体
- **コース取り** — コーナーの外は実距離が延びる。高速コーナリングでは遠心力で外に膨れる(器用さ・馬場状態で変化)
- **馬場** — 良〜不良、開催週による内側の荒れ(見た目にも反映)、道悪適性とパワー
- **坂** — 東京のだんだら坂、中山・阪神の急坂、京都「淀の坂」を標高プロファイルで再現
- **風** — 風向・風速が区間ごとに向かい風/追い風として作用
- **ゲート** — 反応速度でスタートが決まる。早押しは「あおって出遅れ」
- **手前替え / ムチ** — 直線入口でのタイミング、完歩に合わせたムチ。使うほど反応は鈍る
- **叩き合い** — 並ぶと根性のある馬がもうひと伸び
- **斜行と審議** — 後続の進路を十分な間隔なく塞ぐと降着
- **AI騎手** — 残りスタミナから逆算したペース、脚質ごとの位置取り、風除け・進路探し、日ごとの展開(ハイ/スロー)

レース後は スタート・折り合い・コース取り・風除け・ペース配分・手前替え・ムチ を採点した「騎乗評価」が出ます。

## 収録コース・レース

| 競馬場 | 特徴 | レース |
|---|---|---|
| 東京(左) | 直線525.9m・だんだら坂・富士山・大ケヤキ | 芝2400m / 芝1600m |
| 中山(右) | 直線310m・ゴール前急坂・高低差5.3m・冬枯れの芝と西日 | 芝2500m / 芝1200m |
| 京都(右) | 淀の坂・平坦な直線・内馬場の池と白鳥 | 芝3000m |
| 阪神(右) | 外回り・ゴール前急坂・桜並木・六甲の山並み | 芝1600m / 芝2200m |

天候(晴/曇/小雨/雨)・馬場・風・開催週はレースごとに変化し、出走馬とオッズ(AI同士の模擬レースから算出)も毎回生成されます。

## サウンド

音源ファイルは使わず、すべて Web Audio でその場合成しています(楽曲はオリジナル)。
ファンファーレ、メニューBGM、展開に応じて厚みが増すレースBGM、歓声・蹄音・風・雨・ゲート音、音声合成による実況。
設定でレースBGMを切ると場内の音だけになります。

## 構成

```
index.html / css/style.css
js/data.js      競馬場・レース・出走馬生成
js/track.js     コース形状と高低差
js/sim.js       レース物理とAI騎手 (DOM非依存)
js/scene.js     競馬場の3D描画 (Three.js)
js/horse3d.js   馬と騎手のモデル・襲歩アニメーション
js/audio.js     BGM・効果音・実況
js/main.js      進行・入力・HUD
tools/          Nodeでの検証 (npm run simtest)
vendor/         three.js (MIT)
```
