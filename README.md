# ターフジョッキー — 3D競馬ジョッキーシミュレーション

騎手になって手綱を取る、技術勝負の3D競馬ゲームです。ブラウザだけで動作し、ビルドもインストールも不要です。
(馬名・騎手名・レース名はすべて架空です。コースの諸元は実在の競馬場を参考にしています)

## 遊び方

```bash
npm start          # = python3 -m http.server 8080
# → http://localhost:8080 を開く
```

ES Modules を使っているため、`index.html` を直接開くのではなく HTTP サーバー経由で開いてください
(GitHub Pages などの静的ホスティングにそのまま置けます)。

| 操作 | キーボード | タッチ |
|---|---|---|
| 追う(加速) / 離すと「持ったまま」 | ↑ / W | 追う |
| 抑える | ↓ / S | 抑える |
| 進路を左右へ | ← → / A D | ◀ ▶ |
| スタート(ゲートが開いた瞬間) / ムチ | SPACE | ムチ |
| 手前替え(直線入口) | SHIFT / E | 手前 |
| 視点切替 / 一時停止 | C / P | 画面右上 |

発走は画面中央の信号が赤「待て」から緑「GO!」に変わった瞬間に SPACE(タッチは「スタート」)。
レース中は「騎乗アドバイス」が状況に応じて次に押すキーを示します(設定でオフ、難易度「名手」では非表示)。

## 再現している駆け引き

- **スタミナとペース配分** — 有酸素速度を超えた分だけ加速度的に消耗。前半の貯金は直線の失速で倍返しになる。使い切ると時間とともにさらに脚が止まる
- **折り合い** — 気性の激しい馬は序盤・スローペース・下り坂・1周目スタンド前の歓声で掛かる。前に馬を置く(壁を作る)と落ち着く
- **スリップストリーム** — 他馬の真後ろで風の抵抗を軽減。向かい風の日ほど効く。ただし「前が壁」のリスクと表裏一体
- **コース取り** — コーナーの外は実距離が延びる。高速コーナリングでは遠心力で外に膨れる(器用さ・馬場状態で変化)
- **馬場** — 良〜不良、開催週による内側の荒れ(見た目にも反映)、道悪適性とパワー
- **坂** — 東京のだんだら坂、中山・阪神の急坂、京都「淀の坂」を標高プロファイルで再現
- **風** — 風向・風速が区間ごとに向かい風/追い風として作用
- **ゲート** — 反応速度でスタートが決まる。早押しは「あおって出遅れ」
- **手前替え / ムチ** — 直線入口でのタイミング、完歩に合わせたムチ。使うほど反応は鈍る
- **叩き合い** — 並ぶと根性のある馬がもうひと伸び
- **斜行と審議** — 後続の進路を十分な間隔なく塞ぐと降着
- **AI騎手** — 残りスタミナから逆算したペース、脚質ごとの位置取り、風除け・進路探し、日ごとの展開(ハイ/スロー)

レース後は スタート・折り合い・コース取り・風除け・ペース配分・手前替え・ムチ を採点した「騎乗評価」が出ます。

## 馬と騎手のモデル (Blender)

馬・騎手・馬具は Blender の Python API で生成しています (`tools/blender/build_models.py` → `assets/horse.glb`)。

- 胴・肩・後躯・四肢の筋肉と関節、腱、頭部を解剖学的な塊として配置し、滑らかに融合して表面を抽出
- Blender でスムージング・ポリゴン削減・スムーズシェーディング、骨格(馬27本 + 騎手12本)とスキンウェイトを設定
- 頭絡・手綱・競走鞍・ゼッケン、前傾姿勢の騎手(ヘルメット・ゴーグル・勝負服・長靴)を同じ骨格にバインド
- ゲーム側では骨を直接動かし、着地順(左後→右後→左前→右前→空中期)と手前に従う襲歩を再生。毛色ごとの四肢の黒み、流星・白い脚は個体ごとに変化

```bash
pip install bpy scikit-image
python tools/blender/build_models.py assets/horse.glb [確認用レンダリングの出力先]
python tools/blender/build_trees.py assets/trees.glb   # 広葉樹・桜・針葉樹
python tools/blender/build_stand.py assets/stand.glb   # スタンド1スパン(AO焼き込み)
```

### スタンドと周辺

- スタンドは幅10mの1スパンを Blender で作り(階段状の客席、ガラスのカーテンウォールと方立、スラブ、片持ち大屋根の主梁・母屋、柱、照明、通路口)、Cycles でアンビエントオクルージョンを頂点に焼き込んでいます。ゲーム側でスパンを並べて各場の長さ・高さに合わせます
- 客席は段ごとに観客の列を立て、直線では歓声に合わせて波打ちます。エプロンの立ち見客は人型
- 太陽がスタンドの背後にあるときは、屋根の高さから計算した影がコースに落ちます
- 場外は道路と街区のある市街地、マンション・オフィス・戸建てを配置

## サウンド

音源ファイルは使わず、すべて Web Audio でその場合成しています(楽曲はオリジナル)。ホールの残響とリミッターを通して出力します。

- **BGM**: タイトル(弦・ハープ・ホルン) / 出馬表(ピアノ) / ファンファーレ(小太鼓のロール→金管の主題→全奏、観客の手拍子と歓声つき) / レース(蹄のリズムの弦 → 打楽器 → 金管と、展開に応じて3段階に厚くなる) / 勝利のジングル
- **蹄音**: 1発ずつサンプル単位で合成(`js/hoof.js`)。地面に響く低音、芝を踏み抜く「ドスッ」、かかと→つま先の二段の当たり、跳ね上がる芝と土の粒、落ちてくる土塊。道悪では水を含んだ音。襲歩の4拍(後肢→後肢→前肢→前肢を畳みかけて空中期)を強弱つきで鳴らし、周囲の馬(最大12頭)の足音を距離と左右の位置に合わせて重ねる。スタンド前では反響がつく
- **馬の息づかいと馬具**: 完歩ごとの強い呼気(鼻翼が震える音)と吸気、ハミや鐙の金属音。ゲートの中では扉を蹴る音や足踏み
- **歓声**: 観客の声をサンプル単位で合成。背景のざわめき・大歓声・沸く歓声・どよめきは、声帯の振動を日本語の母音の響きに通した声を百人単位で重ねたもの(`js/crowd.js`)。その上に、一人ひとりの掛け声「いけー」「そのままー」「差せー」「残せー」「きたー」「がんばれー」などと、発走前の話し声をフォルマント合成(`js/voice.js`: 声帯の脈動、母音の口の形の移り変わり、か・た行の破裂、さ・し行の擦れ、ま・な・ん行の鼻音、ら行のはじき、叫び声の抑揚と揺れ)で作り、スタンドの方向のあちこちから上げる。近い人ははっきり、遠い人はこもって聞こえる。手拍子や指笛も混じる。合成は Web Worker(`js/sfx-worker.js`)で行う
- **場内の音**: ゲートの開閉音、ムチ、風、雨、接触
- **展開の表現**: 実況(読み上げ・字幕)は行わず、歓声で表現します(発走、1周目スタンド前、4コーナー、直線入口、残り200m、先頭交代のどよめき、接戦、入線後の拍手)
- ブラウザは操作があるまで音を出せないため、最初のタップ/クリックで開始します(タイトルに状態を表示)。iPhone は消音スイッチがオンでも鳴るよう再生カテゴリを切り替えています
- 設定で 全体 / BGM / 効果音 の音量、レース中BGMのオン・オフ、テスト音

## 構成

```
index.html / css/style.css
js/data.js      競馬場・レース・出走馬生成
js/track.js     コース形状と高低差
js/sim.js       レース物理とAI騎手 (DOM非依存)
js/scene.js     競馬場の3D描画 (Three.js)
js/horse3d.js   馬と騎手(glTF)の読み込み・襲歩アニメーション
js/audio.js     BGM・効果音・歓声
js/hoof.js      蹄音・呼吸・馬具の音の合成
js/crowd.js     観客の声(群衆)の合成
js/voice.js     観客ひとりの掛け声・話し声のフォルマント合成 (どちらも js/sfx-worker.js で裏のスレッドから呼ぶ)
js/main.js      進行・入力・HUD
assets/         Blenderで生成した馬・騎手・樹木・スタンドのモデル
tools/          Nodeでの検証 (npm run simtest) / tools/blender モデル生成 / render_hoof_preview.mjs・render_crowd_preview.mjs 試聴ファイル書き出し
vendor/         three.js と glTFローダー (MIT)
```
