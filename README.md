# あやかし釣り / Yokai Fishing

和風の沼や水辺で妖怪魚を釣り、図鑑を埋めて水槽に飾る Roblox ゲームです。
遊びの仕組みは「投げる → 待つ → 引き上げる」の1つだけ。やり込みは魚・釣り場・時間・天気などの**データ**で増やします。

> コードはすべて [Rojo](https://rojo.space/) で Roblox Studio と同期する Luau です。画像・音・メッシュの外部アセットは使っていません(魚も村も地形もすべてコードで生成)。

## フォルダ構成

```
default.project.json   Rojo の設定(ReplicatedStorage / ServerScriptService / StarterPlayerScripts)
src/shared/            サーバーとクライアントの両方で使う
  Config/              ★ゲームデータ(魚・釣り場・レア度・竿・エサ・依頼・課金・調整値)
  Lib/                 抽選・売値・時計・魚の見た目生成などの共通処理
  Locale/              日本語・英語の文言
src/server/            サーバー
  Services/            データ保存・釣り・お店・依頼・ランキング・水槽・ぬし・課金・分析
  World/               地形・沼・村・光の生成
src/client/            クライアント(UI と演出。結果を決めるのはサーバー)
tests/                 Lune で動くテストと経済シミュレーション
docs/                  設計・安全・公開手順・データの足し方・魚のデザイン(FISH_DESIGN.md)
tools/                 魚のデザイン表の生成・見た目の書き出し・Blender でのアニメ風モデル作成(tools/blender)
assets/fish/           アニメ風モデル(YokaiFishMeshes.glb)。Studio で読み込んで ReplicatedStorage.FishMeshes に置く
assets/sounds/         鳴き声(YokaiCries.ogg)。アップロードして ID を Config/Cries.luau の soundId に入れる
```

## 使い方

1. ツールを入れる: `rokit install`(rojo / stylua / selene / lune が `rokit.toml` のバージョンで入ります)
2. Studio に Rojo プラグインを入れ、`rojo serve` → Studio の Rojo プラグインで Connect
3. Studio の「ゲーム設定 → セキュリティ → API サービスへの Studio アクセスを有効化」をオンにすると保存も試せます(オフでも一時データで遊べます)
4. Play で遊ぶ。最初に沼の桟橋に出ます

ビルドだけなら `rojo build -o YokaiFishing.rbxl`。

### チェック

```bash
stylua --check src tests          # 書式
lune run tests/run.luau           # 単体テスト(抽選確率・売値・時計・設定の整合性・文言・魚の見た目生成)
lune run tests/world_smoke.luau   # 沼と村の生成が最後まで動くか
lune run tests/server_sim.luau    # サーバーの結合テスト(偽の DataStore/Players の上で本物のサーバーを動かす)
lune run tests/client_sim.luau    # 画面のテスト(偽の Instance の上で本物の画面を動かし、ボタンを押して確かめる)
lune run tests/economy_sim.luau   # 進行ペースのシミュレーション
```

GitHub に push すると `.github/workflows/ci.yml` が同じチェックを自動で実行します。
