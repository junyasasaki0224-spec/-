# みなとグランプリ — 3D ボートレース

ブラウザで遊べる 3D ボートレース(競艇)ゲームです。Three.js による描画と WebAudio による合成サウンドだけで作られており、画像・音声ファイルは一切使っていません。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド済みの `dist/game.js` を同梱)。

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| スロットル全開 | `↑` / `W` / `Space` | 「全開」 |
| レバーを落とす(減速) | `↓` / `S` | 「減速」 |
| ハンドル | `←` `→` / `A` `D` | `◀` `▶` |
| カメラ切替(追尾 / 接近 / 中継 / 上空) | `C` | 🎥 |
| ミュート / ポーズ / やり直し | `M` / `Esc` / `R` | 🔊 / ⏸ |

ゲームパッド(左スティック + RT/LT)にも対応しています。

### ルール

- 6艇立て・左回り3周。艇番の色は 1白 / 2黒 / 3赤 / 4青 / 5黄 / 6緑。
- **フライングスタート方式**: 大時計の針が 0 を指してから 1 秒以内にスタートラインを通過します。
  0 より早く通過すると**フライング(失格)**。助走距離を計って全開にするタイミングが勝負です。
  初級・中級では「今全開にしたら ST がいくつになるか」を示すアシストバーが出ます。
- 1〜3コースは助走の短いスロー、4〜6コースは助走の長いダッシュ(枠なり進入)。
- ターンマークは外側を回ります。内側を抜けると周回が進みません。

### 走りのコツ

- 全開のままハンドルを切ると艇は外へ大きく流れます。ターンの手前でレバーを落とすと小さく回れます。
- 他艇の航跡(引き波)に乗るとグリップと伸びが落ちます。
- 艇どうしは接触します。内を突く「差し」、外から被せる「まくり」で前に出ましょう。

## 主な要素

- **物理**: 推力・水の抵抗・限界のある横グリップによる慣性ドリフト、風見効果、艇どうしの剛体衝突(角運動量あり)、ターンマーク/消波装置との接触、引き波の影響。
- **AI**: 大時計を見て起こしのタイミングを合わせ、進入 → 旋回 → 立ち上がりのラインを状況に応じて組み立てます。決まり手(逃げ / 差し / まくり / まくり差し / 抜き)も判定。
- **水の表現**: 手続き的な波とフレネル反射、太陽やナイター照明の照り返し、航跡の泡、ルースターテール・舷側・旋回時の水しぶき、レンズに付く水滴。
- **会場**: 架空の「みなと競艇場」。大時計、センターポールと空中線、ターンマーク、消波装置、距離標識、スタンドと観客、審判塔、対岸の大型映像装置(順位をリアルタイム表示)と広告看板、ピット、ナイター照明塔、湾岸の斜張橋・港湾クレーン・街並み。デイ / 薄暮 / ナイターを選べます。
- **サウンド**: 2ストロークエンジン(回転数・ドップラー・定位)、水切り音、しぶき、衝突音、観客のざわめきと歓声、チャイムとファンファーレ。

## 開発

```sh
npm install
npm run build   # src/ を dist/game.js にバンドル
npm run dev     # 監視ビルド + ローカルサーバー
npm run sim     # ヘッドレスで AI レースを回して挙動を確認
```

```
src/sim/   物理・AI・レース進行(描画に依存しない)
src/gfx/   水面・空・艇・会場・水しぶき
src/audio.js / hud.js / input.js / main.js
```
