# みなとグランプリ — 3D ボートレース

ブラウザで遊べる 3D ボートレース(競艇)ゲームです。艇・レーサー・会場のモデルは Blender で生成し、描画は Three.js、音は WebAudio の合成だけで鳴らしています(画像・音声ファイルは使っていません)。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド済みの `dist/game.js` を同梱。モデルもこの中に埋め込み済み)。

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| スロットル全開 | `↑` / `W` / `Space` | 右のスロットルレバーを押し上げる |
| レバーを落とす(減速) | `↓` / `S` | レバーを下げる / 離す |
| ハンドル | `←` `→` / `A` `D` | 左のハンドルレバーを左右に倒す |
| カメラ切替(追尾 / 接近 / オンボード / 中継 / 上空) | `C` | 🎥 |
| ミュート / ポーズ / やり直し | `M` / `Esc` / `R` | 🔊 / ⏸ |

ゲームパッド(左スティック + RT/LT)にも対応しています。タッチ操作はレバー式で、スロットルは開度を無段階に調整できます(設定で「離した位置で止める」に変更可)。

### モード

- **シングルレース**: 好きな枠で1レース。
- **グランプリ**: 予選2走(外枠と内枠を1回ずつ) + 優勝戦。着順に応じた得点で優勝戦の枠が決まり、優勝戦の1着が優勝。
- **スタート練習**: スタートだけを繰り返し練習。

### ルール

- 6艇立て・左回り3周。艇番の色は 1白 / 2黒 / 3赤 / 4青 / 5黄 / 6緑。
- **フライングスタート方式**: 大時計の針が 0 を指してから 1 秒以内にスタートラインを通過します。
  0 より早く通過すると**フライング(失格)**。「今全開にしたら ST がいくつになるか」を示すアシストバーを設定で表示できます。
- 1〜3コースは助走の短いスロー、4〜6コースは助走の長いダッシュ(枠なり進入)。
- ターンマークは外側を回ります。内側を抜けると周回が進みません。

### レース前に決めること

- **チルト角度**: モーターの取り付け角度。下げる(-0.5°)と出足と回り足、上げる(+3.0°)と伸び(最高速)が良くなります。
- **モーター**: レースごとに抽選され、2連率が高いほど少しだけ出力が上です。
- **水面状況**: 風向・風速・波高が毎回変わります。向かい風は助走が伸びにくく、追い風はスタートが早くなりがち。波が高いと艇が暴れ、グリップが少し落ちます。

### 走りのコツ

- 全開のままハンドルを切ると艇は外へ大きく流れます。ターンの手前でレバーを落とすと小さく回れます。
- 水面の矢印(**ガイドライン**)が理想の走行ライン。赤くなったらレバーを落とす合図です(設定でオフにできます)。
- 他艇の航跡(引き波)に乗るとグリップと伸びが落ちます。
- 艇どうしは接触します。内を突く「差し」、外から被せる「まくり」で前に出ましょう。
- レース後は**リプレイ**を中継カメラで見られます(`1`〜`6` で追う艇を変更)。

## 主な要素

- **物理**: 推力・水の抵抗・限界のある横グリップによる慣性ドリフト、風見効果、艇どうしの剛体衝突(角運動量あり)、ターンマーク/消波装置との接触、引き波、風と波、チルト角度。
- **AI**: 6人のレーサーに腕前・スタートの鋭さ・得意戦法があり、大時計を見て起こしのタイミングを合わせ、進入 → 旋回 → 立ち上がりのラインを状況に応じて組み立てます。決まり手(逃げ / 差し / まくり / まくり差し / 抜き)も判定。
- **水の表現**: 波の法線テクスチャ + フレネル反射 + 平面リフレクション(艇・会場・空が水に映る)、航跡の泡、ルースターテール・舷側・旋回時の水しぶき、霧、レンズに付く水滴、水面に落ちる艇の影。
- **会場**: 架空の「みなと競艇場」。大時計、センターポールと空中線、ターンマーク、消波装置、距離標識、片持ち屋根のスタンドと観客、審判塔、対岸の大型映像装置(順位をリアルタイム表示)と広告看板、ピット、ナイター照明塔、湾岸の斜張橋・港湾クレーン・街並み。デイ / 薄暮 / ナイター。
- **ライティング**: PBR + 空から作る環境マップ、艇のシャドウマップ、会場全体の太陽の影、AO の焼き込み、ブルーム、ACES トーンマッピング。
- **サウンド**: 2ストロークエンジン(回転数・排気の共鳴・ドップラー・定位)、水切り音、しぶき、衝突音、観客のざわめきと歓声、チャイムとファンファーレ、実況の読み上げ(ブラウザの音声合成に対応している場合)。
- **画質設定**: 高 / 中 / 低。自動にすると重い端末では段階的に下げます。

## 開発

```sh
npm install
npm run build   # src/ と assets/models/*.glb を dist/game.js にバンドル
npm run dev     # 監視ビルド + ローカルサーバー
npm run sim     # ヘッドレスで AI レースを回して挙動を確認
```

```
src/sim/      物理・AI・レース進行・レーサー名簿(描画に依存しない。同じ設定と入力から同じレースを再現できる)
src/gfx/      描画: stage(レンダラー/影/画質) water boat venue spray guide camera
src/*.js      audio / commentary / hud / input / main
assets/blender/  モデルを生成する Blender (bpy) スクリプト
assets/models/   生成済みの GLB
```

### 3Dモデルの作り直し

モデルは Blender の Python モジュールで手続き的に生成しています(艇体のロフト、スキンモディファイアで作るレーサー、AO の頂点カラーへの焼き込み)。

```sh
pip install bpy            # Blender を Python モジュールとして入れる
BLENDER_PY=python3 sh assets/build.sh
npm run build
```
