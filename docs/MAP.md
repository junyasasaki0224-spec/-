# マップ(沼・釣り村)

マップはすべてコードで作っています(`src/server/World/`)。サーバーが起動した時に地形とパーツを生成します。
どちらの釣り場も「山に囲まれた谷」で、地形の端や何も無い空間は見えません。山の手前には見えない壁があり、外へ落ちることもありません。

## 沼(最初の釣り場)

出現地点は南の岸。そこから北を向くと、池・島の祠・神木・滝・竹林が一度に見える配置にしています。

| 場所 | 中身 |
| --- | --- |
| 出現地点 | 石畳の小さな広場。目の前に桟橋 |
| 桟橋 | 綱の手すり付き。先は何人かで並んで釣れる広い釣り台。脇に小舟がつないである |
| 池 | 蓮・葦・水から突き出た枯れ木・霧・蛍(夜) |
| 島の祠 | 小さな鳥居と祠(青い灯り) |
| 神木 | 北西の杉林の中の大樹。しめ縄と紙垂、石の玉垣。島の祠の向こうに見える目印 |
| 沢と滝 | 北東の山から段になって池へ落ちる。滝つぼにしぶき |
| 竹林 | 北東の岸の向こう |
| 杉の森 | 北の岸の向こう。山の斜面にも杉が続く |
| 狸の行商 | 出現地点の西(魚を売れる) |
| 村への鳥居 | 出現地点の東。道ばたにお地蔵さまが3体 |
| VIP の釣り座 | 南東の岸から池へ張り出した朱塗りの台 |
| 道 | 出現地点から 行商 / 鳥居 / VIP の釣り座 / 神木 へ土の道(地形の材質を塗るだけなのでパーツは増えない) |

## 釣り村(ぬしの湖)

鳥居をくぐると、湖へまっすぐ下る表通りに出ます。

| 場所 | 中身 |
| --- | --- |
| 鳥居と表通り | 石畳。両側の柱に提灯の列(夜に灯る)。入口に桜 |
| お店 | 通りの西に魚屋(狸)・竿屋、東にエサ屋・妖怪退治の道場。向かい合わせ |
| 見物台 | 通りの先の湖畔。手すり付きの台で、ぬし釣りの時はここに集まる。脇に依頼板 |
| ぬしの湖 | 蓮・蛍(夜)。まわりを石灯籠と石の道がめぐる |
| 釣り小屋 | 湖の北に10軒(水槽)。石の道から小道が通っている |
| ランキング看板 | 湖の向こう側(通りと見物台から正面に見える) |
| 五重塔 | 北西の山の中腹。村のどこからでも見える目印 |

## 作り方の決まり

- 地形: `Terrain.build` が池/湖を中心にした「すり鉢」と、外側の山の輪(`ring`・`ringHeight`)を作る。山すそは角度で揺らし、峰の高さも場所ごとに変える。斜面は森の緑、峰とところどころが岩
- 見えない壁: `Scenery.boundary`(36枚、山すそのすぐ外)。透明・当たり判定あり・調べ(Raycast)には引っかからない
- 道: `Terrain.paintPath`(地面の高さは変えず、表面の材質だけ塗り替える)
- 景色の部品: `Scenery.luau`(杉・竹林・神木・お地蔵さま・枯れ木・小舟・五重塔・提灯の列・見物台・山の森・滝しぶき)
- 重さ: パーツ約1,900(上限の目安 5,000)、地形の操作 約1.5万回(起動時に1回だけ)。夜の灯りは提灯と石灯籠だけ
- テスト(`lune run tests/world_smoke.luau`): 見えない壁があること、出現地点・お店・鳥居・看板などボタンの付いた物がすべて壁から 10 スタッド以上内側にあること、目印があること、パーツ数

## 見た目の確認(Roblox を開かずに)

ゲームと同じ生成コードでマップを作り、Blender で絵にできます(配置と景色の確認用。Roblox の光・霧・水の揺れは無い)。

```bash
lune run tools/map/export_map.luau build/map.json
python tools/map/render_map.py build/map.json build/map_renders            # 昼(Blender 4.2 か pip の bpy)
python tools/map/render_map.py build/map.json build/map_renders --night    # 夜(石灯籠・提灯が灯る)
```

`--views swamp_spawn,village_spawn` で一部だけ。視点は 真上(`*_top`)・空から(`*_air`)・出現した時の画面(`*_spawn`)・桟橋(`swamp_pier`)・見物台から小屋(`village_huts`)。
