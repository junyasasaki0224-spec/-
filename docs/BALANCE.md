## 相棒の育成(経験値 = 10 × Lv^1.5 で次のレベル)

沼の魚を平均的に食べさせた場合(1匹あたり約34 XP、1匹約25秒)の目安。1匹の相棒あたり:

| 目標 | 必要な魚 | 釣りの時間の目安 |
| --- | --- | --- |
| Lv10 | 約35匹 | 約14分 |
| Lv20 | 約200匹 | 約80分 |
| Lv30 | 約550匹 | 約4時間 |
| Lv40 | 約1,150匹 | 約8時間 |

実際は 同じ属性の魚(1.5倍)・レアな魚・妖怪退治の経験値(敵のレベル合計 × 9)でずっと速くなります。
最後の「沼のぬし」(Lv36〜40)は長期目標として、相性の良いレアな相棒なら Lv30 前後で勝てる強さにしています。

## 気づいたこと
- 「次の釣り場まで数十分〜数時間」という狙いに対して、川・滝つぼ・夜の湖はほぼ狙いどおり。
- **夜の湖 → 海(400万)は約23時間**と急に重くなります。海を公開する更新までに、(a) 夜の湖の魚の基本売値を上げる、(b) 海の解放額を下げる、(c) 依頼の報酬を釣り場倍率に比例させる、のどれかで調整するのがおすすめです。実データを見てから決めてください。
- 2倍の運パスの効果は進行速度で約1.7倍。強すぎず弱すぎない範囲です。
- 自動釣りは手動の7割の速さで、レアほど成功率が下がる(伝説50%・秘伝20%)ため、レア狙いは手動が得になります。

## 見直し(今遊べる 沼 + ぬしの湖 で確かめたこと)

`tests/economy_sim.luau` はまだ無い釣り場(川〜竜宮)の解放を見ているので、今遊べる内容でも測り直しました(手動・成功率はレアほど下がる前提)。

| 釣り場 | 1匹の平均の売値(竿1 / 竿10) | 1時間の稼ぎ(竿1 / 竿10) |
| --- | --- | --- |
| 沼 | 約110 / 約190 | 約1.9万 / 約3.5万 |
| ぬしの湖 | 約190 / 約300 | 約3.3万 / 約5.4万 |

竿を買える時間の目安(稼ぎの良い方で売れる魚は全部売る): 竿2 = 2〜4分、竿3 = 約10分、竿5 = 約50〜70分、竿6 = 約2〜3時間、竿8 = 約20時間、竿10 = 約150時間。
竿8以降は、海・竜宮(売値 8〜50倍)を公開した後の目標なので、今はこのままにしています。

直したこと:

- **ぬしの湖は3段目の竿から釣れるようにした**。湖は最初の鳥居のすぐ先で、売値は沼の1.5倍・平均では約1.7倍。初めから釣れると、最初の1匹のあと沼へ戻る理由がありませんでした。3段目の竿は沼で約10分なので、「沼で竿を育てて → 湖へ」という最初の目標になります。村へ行く・店・依頼・水槽・道場・ぬし釣りは竿に関係なく誰でもできます。竿が足りないまま湖で投げると、理由がメッセージで出ます
- **妖怪退治の再戦の小判を、相手ごとに1日1回にした**(経験値は何度でも満額)。1回の戦い(2〜3分)で再戦の小判が出続けると、たとえば沼のぬしの再戦は1時間で約70万小判と、釣り(1時間3〜5万)の十倍以上になり、釣りをする理由が無くなっていました。1日の切り替えは依頼と同じ(日本時間 4:00)

そのままにしたこと:

- 朝だけの魚(木霊鯉・鳳凰鯉)は、20分の1日のうち約2.5分しか出ません。同じレア度の夜の魚より数倍出にくいですが、「時間を合わせて狙う」魚として意図どおりです(画面に時刻が出ています)
- 秘伝(八岐提灯・月読鯉)は天気と時間の両方の条件があり、数百時間に1匹ほど。運のお札・2倍の運パスで大きく縮みます
- 相棒の育て方、依頼、デイリー報酬、ぬし釣り(5分で1人でも届く量)は問題なし

## 引き上げ(網のゲージ)の手応え — 2026年11月の見直し

本物の `ReelGame` を、人のように操作するボットで各200回遊んで測った(`lune run tools/sim/reel_sim.luau`)。
上手な人 = 反応0.2秒・ミス5%、はじめての人 = 反応0.4秒・ミス15%(どちらも「少し前の様子を見て押す」)。

**直す前**: 竿1で、上手な人でも ふつう(common)の魚を 70% しか釣れず、はじめての人は 38%。上(uncommon)は 36% / 14%。
最初の1匹(案内で必ず釣れる)の直後から、半分以上の魚に逃げられる作りだった。反応が0.1秒の名人だとほぼ100%なので、
「反応の速さ」で差がつきすぎていた(子ども・スマホは不利)。

**直したもの**: 網の大きさ 0.26 → 0.30、枠の中で張りが戻る速さ 0.10 → 0.12、張りのたまる速さ(tensionRate)を
ふつう −25%・上 −25%・稀 −15%・極 −10%・伝説 −8%・幻 −6%(秘は据え置き)。魚の速さと引き上げの時間は変えない。

| レア度 | 竿1 上手 / はじめて | 竿6 上手 | 竿10 上手 / 名人 |
| --- | --- | --- | --- |
| 最初の1匹 | 100% / 100% | — | — |
| ふつう | 98% / 96% | 100% | — |
| 上 | 88% / 62% | 97% | — |
| 稀 | 50% / 16% | 88% | — |
| 極 | 11% / 2% | 56% | — |
| 伝説 | 2% / 0% | 21% | 53% / 100% |
| 幻 | 0% / 0% | 7% | 27% / 98% |
| 秘 | 0% / 0% | 1% | 9% / 67% |

- ふだんの魚(ふつう・上)は気持ちよく釣れ、竿を上げるほど上のレア度が釣れるようになる(竿の価値がはっきりする)
- 幻・秘は「腕と道具の試験」。上手な人でも最高の竿で 3割 / 1割。自動釣りのパス(autoSuccess)は別の道
- これはボットの数字。人は予測して動かせるので、たぶんもう少し釣れる。**公開後は分析のカスタムイベント `Catch_<レア度>` と `Escape_<レア度>` の比で、レア度ごとの成功率を見て直す**
