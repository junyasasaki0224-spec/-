# 妖怪魚デザイン(第2版)

ゲームの見た目は `src/shared/Lib/FishBuilder.luau` が、魚の表(`Config/Fish/*.luau`)の形・色・模様・飾りから組み立てます。
プレビューは `lune run tools/export_fish.luau out.json` で書き出したデータをブラウザで描いたものです。

## デザインのルール

### 1. レア度は色と飾りの量で見せる
| レア度 | ルール |
| --- | --- |
| 並 | 自然で落ち着いた色。飾りは0〜1つ |
| 上 | はっきりした2色と、妖怪の特徴を1つ |
| 特上 | 彩度を上げ、一目で分かる記号(提灯・傘・皿) |
| 極 | 強い色と差し色、特徴を2つ以上 |
| 伝説 | 金の差し色と、光や炎 |
| 神話 | 大きくして発光させ、龍の格 |
| 秘伝 | すべての飾りを載せた唯一の一匹 |

### 2. 共通の体のつくり
- 3段のシルエット: 胴 → くびれた尾の付け根 → 尾びれ
- 顔: 白目・黒目・光の点の3層の目と、形ごとの口
- ひれ: 差し色を白に少し寄せ、わずかに透かす
- 背中を少し濃くして、上からの光でも立体に見せる
- 差し色(`c3`)はひれ・角の先・皿の縁にだけ使い、色数を絞る

### 3. 6つの体の形
| 形 | 特徴 |
| --- | --- |
| 鯉型 | 二股の尾と帆の背びれ |
| 鯰型 | 平たい頭と横長の口、ひげ |
| 河豚型 | 丸い体にトゲ、大きな目 |
| 鰻型 | 背から尾へ続くリボンのひれ |
| 提灯型 | 大あごと牙、背のトゲ |
| 鱏型 | ひし形の翼と鞭の尾、目は背中側 |

## 新しい魚をデザインするとき
1. まずレア度を決め、ルール1の色と飾りの量に合わせる
2. 元の妖怪の「一目で分かる記号」を1つ選ぶ(皿・傘・提灯・一つ目など)
3. 体・模様・差し色の3色に絞る。差し色は記号の部分に使う
4. `lune run tools/export_fish.luau` で書き出して見た目を確認する
