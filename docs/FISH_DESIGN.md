# 妖怪魚デザイン(第3版・91種)

ゲームの見た目は `src/shared/Lib/FishBuilder.luau` が魚の表(`Config/Fish/*.luau`)から組み立てます。
魚の表は `tools/fish_designs.py` で一覧管理しています(見た目の項目を直したら `python3 tools/fish_designs.py` で表を作り直す)。
見た目の確認は `lune run tools/export_fish.luau out.json` で書き出したデータをブラウザで描いて行います。

## ルール1: レアな魚ほど大きく、派手に

レア度の格は FishBuilder が全魚に自動で付けます(`RARITY_STYLE`)。データ側は「その魚の個性」だけを書きます。

| レア度 | 大きさ | 加わるもの |
| --- | --- | --- |
| 並 | ×0.75 | つやなし。落ち着いた色、飾りは0〜1つ |
| 上 | ×0.88 | わずかなツヤ。妖怪の特徴を1つ |
| 特上 | ×1.05 | ひれの縁取り。一目で分かる記号 |
| 極 | ×1.30 | 2枚目の背びれ、光の粒、特徴を2つ以上 |
| 伝説 | ×1.70 | 金の縁取りと額の金の紋、体が光る。**体の形も大物(鮫・鯱)** |
| 神話 | ×2.15 | 光る瞳、頭の後ろの後光 |
| 秘伝 | ×2.60 | 二重の後光、周りを漂う鬼火 |

並と秘伝で約3.5倍、鮫・鯱は体も長いので、実際の長さは並の鯉の4〜5倍になります。
ゲーム内では、釣果の画面で大物ほど画面いっぱいに映り(並は小さく)、相棒バトルでもレアな魚ほど大きく(並 約5 〜 秘伝 約8.7 スタッド)、
水槽でもレアな魚ほど大きく飾られます(ガラスに収まらない大物は、横向きのままゆったり漂う)。

### 伝説以上は「大物」の形: 鮫と鯱

強くてレアな魚は、シャチやサメのような大きな海の生き物をモチーフにします(妖怪の記号はそのまま)。

- **鮫(shark)**: 先へ細くなる鼻先、後ろへ傾いた高い三角の背びれ、上の葉が長い三日月の尾、翼のような胸びれ、5本のえらの切れ目、ざらざらの肌。口は `jaws`(にやりとした歯の列)
- **鯱(orca)**: 丸く太い頭と体、まっすぐ高い背びれ、横に広がる尾びれ、うちわ形の胸びれ、つるつるの肌。模様は `orca`(c1 が黒の部分、c2 が白いお腹・目の後ろの楕円・横腹の白)
- ひれは体と同じ色で、伝説以上の金の縁取りが付く
- 相棒バトルの能力も大物向け(鮫 = 攻めと速さ、鯱 = 体力と力。形の技は「噛み砕き」「大波返し」)
- 龍神(神話)だけは、湖の本当の主として龍の姿のまま

### 釣り場ごとの魚と「強キャラ」

魚はその場所に住んでいそうなものにする(川は鮎・山女魚・岩魚・鰍・鮭、海は鯛・鰯・飛魚・鰹・鮪・太刀魚)。
本当に大きくてレアな魚(鮫・鯱・鯨・大鱏・海の大蛇)は基本は海の生きもの。ほかの釣り場では、その場所らしい強キャラを頂点にする。

| 釣り場 | 頂点の強キャラ(伝説 → 神話 → 秘伝) |
| --- | --- |
| 川 | 幻の伊富魚(鮭型)・水虎 → 大はんざき(山椒魚型。川の主)→ 鮭の大助(鮭型。鮭の王) |
| 海 | 磯撫で(鮫)・金鯱(鯱)・赤えい(大鱏)→ 化け鯨(鯨型。骨の鯨)→ あやかし(海の大蛇。このゲームの名の由来) |

- **鮭(salmon)**: 上へ曲がった下あご、背中のこぶ、脂びれ、大きな二又の尾
- **大山椒魚(salamander)**: 平たく広い頭、4本の短い足と指、尾の上下の低いひれ、いぼいぼの肌と横腹のしわ、頭の上の小さな目
- **鯨(whale)**: 大きく丸い頭、長い胸びれ、小さな背のこぶ、横に広い尾びれ、のどの畝

## ルール2: 一匹ずつの個性

- **目(eyes)9種**: normal / cute / angry(怒り眉) / sleepy(半目) / big(一つ目) / cat(縦長の瞳) / glow(光る目) / dot(点の目) / none
- **口(mouth)13種**: small / wide / o / smile / frown / open / tongue(長い舌) / fangs(牙) / grin(ギザ歯) / geta(下駄の歯) / beak(くちばし) / jaws(鮫の歯の列) / none
- **目印の飾り(deco)38種**: 元の妖怪が一目で分かる記号を選ぶ。例: 河童=皿とくちばし、唐傘=傘と一つ目と舌、雷神=太鼓の輪、猫又=猫耳と鈴と二本の尾、座敷童=おかっぱ
- **体つき(body)**: 幅・高さ・長さの倍率。影だけでも見分けられるように魚ごとに変える(金魚は丸く、ろくろ首は長く)
- **尾の本数(tails)**: 猫又2本、金魚3〜4本、九尾は9本

## ルール3: 共通の体のつくり

- 3段のシルエット: 胴 → くびれた尾の付け根 → 尾びれ
- 目は白目・黒目・光の点の3層
- ひれは差し色を白に寄せて少し透かす
- 背中を少し濃くして立体に見せる
- 差し色(c3)はひれ・角の先・皿の縁などにだけ使い、色数を絞る

## 新しい魚をデザインするとき

1. レア度を決める(大きさと派手さは自動で付く)
2. 元の妖怪の「一目で分かる記号」を1つ選び、deco にする(極以上は2つ以上)
3. 目と口で性格を決める(怒りっぽい・眠たげ・人懐っこい・不気味…)
4. 体つき(body)で影の形を変え、ほかの魚と並べても見分けられるようにする
5. 色は体・模様・差し色の3色に絞る。並は落ち着いた色、レアほど強い色
6. `tools/fish_designs.py` に行を足して実行し、`lune run tools/export_fish.luau` で見た目を確認する
