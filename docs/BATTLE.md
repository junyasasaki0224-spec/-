# バトル画面(水の中の3D)

妖怪退治・オンライン対戦・ボス戦は、同じバトル画面で戦います。舞台は **本物の3Dの水の中** です。

## しくみ

- バトルが始まると、クライアントだけに水中の舞台(`Controllers/BattleArena.luau`)を作り、カメラをそこへ移す。ほかの人には見えず、サーバーへも送らない
  - 舞台は地図のはるか上(`BattleArena.ORIGIN`)。霧と水面で外は見えない。2回目からは作り直さずに使い回す
  - 終わると、カメラ・光の設定・霧を元に戻し、舞台をしまう(`BattleScene.destroy`)
- 光はバトルの間だけ水の中のものにする(`BattleScene` の `UNDERWATER`): 太陽を真上に、青い霧(FogStart 26 / FogEnd 190)、色の補正・ブルーム・被写界深度(奥と手前がぼける)。Atmosphere があると霧が効かないので一時的に外す。時間帯と天気の見た目(`LightingFX`)は `LightingFX.hold` で止めておく(雨も降らない)
- 相棒は本物の3Dモデル(`FishBuilder`。アニメ風メッシュがあればそれ)。影が海底に落ちる。カメラについて回るやわらかい光で、水の中でもはっきり見える
- 勝ち負け・ダメージはサーバーが決める。画面は届いた出来事を順に再生するだけ(`BattleUI` → `BattleScene`)

## 舞台(BattleArena)

| もの | 中身 |
| --- | --- |
| 海底 | 砂の円盤と砂丘、手前に小石・貝・ヒトデ・海草(立体の手がかり。魚の通り道はあける) |
| 岩 | 奥の岩場(苔つき)、左右の岩の柱、遠くの岩壁(霧に溶ける) |
| 妖怪の海 | 沈んだ鳥居(苔むした朱)、石灯籠3基(青い火が灯る) |
| 生きもの | 海月4匹(光る・ふわふわ漂う)、小魚の群れ(奥をぐるりと回る) |
| 海藻 | 13本。根元から先へ、少しずつ曲がりながら揺れる(浮き袋つき) |
| 水 | 下から見上げる水面、斜めに差す光の筋、海底でゆらめく光、割れ目から上る泡、漂う粒(マリンスノー) |

動くもの(海藻・海月・小魚・泡・光)は毎フレームまとめて動かす(`workspace:BulkMoveTo`)。部品は約600。

## カメラ(BattleScene)

| 場面 | 動き |
| --- | --- |
| 始まり | 水面の近くの高いところから、すべり降りる |
| ふだん | 2匹を横から。ゆっくり回りこむように揺れる(手前と奥がずれて立体に見える) |
| 攻撃 | 攻める側の後ろへ回りこみ、寄る。当たった瞬間に少し寄る(画角)+ 揺れ |
| 登場・交代 | 泳いできた子に寄る |
| 倒れる | 水面へ浮かんでいく子を見上げる |
| ボス | 登場と怒った時にボスを大きく |
| 勝利 | 勝った子のまわりを回る(その子は宙返り、紙吹雪の光) |

数字(定位置・ふだんのカメラ・攻撃のカメラ・回る計算)は `BattleArena`(`HOME` / `BASE_SHOT` / `ATTACK_SHOT` / `orbit` / `fishYaw` / `idle`)にまとめ、ゲームと下の確認用の絵で同じものを使う。

## 技の演出(3D)

- 攻撃: 相手へ泳いでぶつかって戻る(泳ぎ出しに水しぶき)。当たった子は光って(Highlight)、のけぞる
- 属性ごと: 水=泡と水の輪 / 火=炎の粒子と橙の光 / 雷=上から落ちる稲妻と閃光 / 土=砂けむりと岩のかけら / 霊=紫の輪と光
- 弱点を突く: 金の輪と大きな揺れ。渾身の一撃: 白い閃光
- 補助・回復: 跳ねて光る輪、回復はきらきらと泡
- 倒れる: お腹を上にして水面へ浮かぶ。泡がはじける
- ボス: まわりに妖気(紫)。怒ると赤く脈打ち、画面が揺れる
- ダメージの数字と鳴き声の吹き出しは、魚について回る(BillboardGui)

## 画面(2D の札)

- 上: 左右に体力の札、真ん中に 手番 / 対戦の残り秒 / ボス戦の残り時間
- 体力の札の下: **⏩ ×1/×2**(演出の速さ。設定に保存)、**🤖 おまかせ**(おすすめの技を自動で使う。そのバトルの間だけ)、**📖 相性**(相性表)
- 下: 技は **お札**(属性の帯・技の名前・威力・判子 1〜4・相手に「◎ 効く!」)。今いちばん良さそうな技に「★ おすすめ」(`Lib/BattleAdvice.luau`。見えている情報だけで選ぶ)
- 操作: キーボード 1〜4、ゲームパッド 十字キー(左・上・右・下 = 1〜4)・Y = 交代・B = 逃げる
- 設定の画面: バトルの速さ ×1/×2、画面の揺れ ふつう/弱い

## 見た目の確認(Studio を開かずに)

```bash
# 3Dの舞台を、ゲームと同じ組み立てコード・本物の魚のメッシュで描く(Blender)
lune run tools/battle/export_battle.luau build/battle.json
python tools/battle/render_battle.py build/battle.json build/battle_renders     # battle / attack / boss / wide

# 画面の札を重ねる(上の絵を後ろに敷く)
UI_SNAPSHOTS=build/ui lune run tests/client_sim.luau
node tools/ui/render_ui.js build/ui build/ui_png --bg underwater=build/battle_renders/battle.png,raid=build/battle_renders/boss.png
```

Blender の絵は霧・ブルーム・粒子を近似したもの。最終確認は Studio で(水の色・霧の濃さ・光の筋の強さは、そこで調整する)。
