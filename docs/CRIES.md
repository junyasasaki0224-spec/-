# 妖怪魚の鳴き声

50種すべてに、その妖怪らしい鳴き声があります(ポケモンの鳴き声のように、一匹ずつ違う)。
音は録音や素材を使わず、`tools/cries/yokai_cries.py` が一から合成しています(生き物の声・鈴・木や骨の音・太鼓・泡・火の粉・雷・風)。

## どこで鳴くか

| 場面 | 鳴き方 |
| --- | --- |
| 釣れた時 | 結果の画面が出て少ししてから鳴き、映像の右上に吹き出し(「ぴゅるる〜」) |
| 図鑑 | 見つけた魚は「🔊 鳴き声」ボタンで何度でも聞ける(未発見は鳴かない) |
| 相棒 | 一覧で相棒を選ぶと返事をするように鳴く。詳しい画面の 🔊 でも聞ける |
| 相棒バトル | 場に出た時に鳴く。倒れた時は低く・ゆっくり鳴く |
| ぬし釣り | ぬしが現れた時と、ぬし釣りに参加した時に、湖の主(龍神)が吠える |

- 設定の「音」をオフにすると鳴き声も止まります(吹き出しは出ます)
- 音は自分にだけ聞こえます(クライアントで鳴らす)。サーバーや保存データは関係しません

## つくり

- **レシピ**: 1匹ずつ、声の高さの動き・母音(あ・い・う…で響きが変わる)・震え・ざらつき・息の量と、鈴・下駄・太鼓・泡などの「物の音」を組み合わせています
- **レア度**: 上がるほど長く、厚くなる。特上からは声を重ね(コーラス)、伝説以上は1オクターブ下の声も重ねて重みを出す。残響も長くなる
- **属性**: 水は泡、火は火の粉、雷は小さな火花、土は低い地鳴り、霊は空気の音とこだまを、主役の声を邪魔しない大きさで混ぜる
- **大きさ**: どの鳴き声も聞こえる大きさをそろえてあります(最大でも -1dB)

全50種の鳴き声は1本の音 `assets/sounds/YokaiCries.ogg`(約2分・約1MB)にまとめてあり、
`src/shared/Config/Cries.luau` に魚ごとの「始まり・長さ(秒)」と吹き出しの文字(日本語・英語)が入っています。
ゲームはその区間だけを鳴らすので、**Roblox にアップロードする音は1つだけ**です。

## Roblox に音を入れる(1回だけ)

1. Studio の **アセットマネージャー**(Asset Manager)の「インポート」、または Creator Dashboard から `assets/sounds/YokaiCries.ogg` を音声としてアップロードする
   - ゲームがグループのものなら、グループとしてアップロードする(個人の音はグループのゲームで鳴らないことがあります)
   - 審査が終わるまで数分かかることがあります
2. アップロードした音の ID(数字)をコピーする
3. `src/shared/Config/Cries.luau` の `soundId = "rbxassetid://0"` を `"rbxassetid://<ID>"` に書き換える
4. プレイして、魚を釣った時・図鑑の「🔊 鳴き声」で鳴くことを確かめる

アップロードする前(`rbxassetid://0` のまま)でも、吹き出しの文字は出ます。ゲームは止まりません。

## 作り直す・新しい魚に鳴き声を付ける

```bash
lune run tools/export_fish.luau build/fish.json
python3 tools/cries/yokai_cries.py --defs build/fish.json --out build/cries \
    --sprite assets/sounds/YokaiCries.ogg --luau src/shared/Config/Cries.luau
```

- 必要なもの: Python 3 と numpy、ffmpeg(ogg / mp3 を作る)、stylua(表の形をそろえる)
- `build/cries/<id>.mp3` に1匹ずつの確認用の音ができます。`--ids hasu_koi,ryujin` で一部だけ作れます(この時は `--sprite` を付けない)
- 新しい魚は `tools/cries/yokai_cries.py` の `CRIES` に `@cry("<id>", "日本語の文字", "English")` のレシピを1つ足します。レシピが無い魚は、体の形・目・レア度から自動で鳴き声を作ります(文字は「…!」)
- 同じレシピからは毎回まったく同じ音ができます。**音が変わると `audioHash` が変わり、`soundId` は 0 に戻ります**(古い音と区間がずれて別の魚の声が鳴るのを防ぐため)。その時は上の「Roblox に音を入れる」をもう一度行ってください

## 確かめる

```bash
python3 tools/cries/check_cries.py --defs build/fish.json
```

できた ogg を実際にほどいて、次を確かめます(1つでも外れたら失敗)。音を作り直したら、アップロードの前に実行してください。

- Roblox に上げられる形か(Vorbis・モノラル・44.1kHz・7分未満・20MB未満)、表の長さと音の長さが合っているか
- 魚ごとの区間に、その魚の鳴き声が入っているか(レシピから作り直した音と重ねて、ずれ 1ms 以内・相関 0.97 以上)
- 区間の外に音がはみ出していないか、区間どうしの間は無音か、音割れしていないか
- 大きさがそろっているか(全員が中央値 ±2dB 以内)
- 参考: 声の高さがデザインした範囲か(蓮鯉 700〜1300Hz、龍神の吠え声 25〜110Hz など)

どの鳴き声も頭に 0.03 秒の無音を入れてあります(区間の頭で少し遅れて鳴り始めても、下駄や瓦の「からん」が欠けないように)。
ゲーム側は、音の読み込みが終わってから鳴らします(2秒待っても読み込めなければ、その回は鳴かせない)。
