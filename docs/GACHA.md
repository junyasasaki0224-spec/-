# 百鬼の祠(ガチャ)

村の左の「⛩ 祠」ボタン(または左上の勾玉の数)から開く。勾玉(まがたま)か祈願札(きがんふだ)で祈ると、
**ここでしか授からない限定の妖怪魚**や道具を授かる。データは `src/shared/Config/Gacha.luau`、抽選は `src/shared/Lib/Gacha.luau`(乱数を外から渡す純粋な関数)、
サーバーは `src/server/Services/GachaService.luau`、画面と演出は `src/client/Controllers/Gacha.luau`。

## 通貨
| | 何 | 1回の値段 |
|---|---|---|
| 勾玉 | 祈るための石。遊んでいればたまる。Robux でも買える | 150 |
| 祈願札 | 1枚で1回。はじめて遊んだ時に5枚、7日続けてログインした日に1枚 | 1枚 |

札を先に使い、足りない分を勾玉で払う。10回は 1500 勾玉(または札10枚)。

## 確率(画面の「確率」にいつも出ている)
| 星 | 確率 | 中身 |
|---|---|---|
| ★5 | 0.6% | テンショウ(天照翻車魚・神話)・ヤマタ(八岐大蛇・秘伝) |
| ★4 | 5.4% | ヒノトリ(鳳凰魚)・コクリュウ(黒龍)・ユキヒメ(雪女の羽衣魚) ※伝説 |
| ★3 | 14% | ギンコ(銀狐の落とし子)・ヨザクラ(夜桜海月)・ゴロピカ(雷神撞木鮫) ※極 |
| ★2 | 30% | 小判(多め)・光る海老×5・高級エサ×3・運2倍10分 |
| ★1 | 50% | 小判・ミミズ×10・団子×5 |

- **天井**: ★4以上は10回に1回は必ず。★5は90回目で必ず(出たら数え直し)。祠の画面に「あと何回」を出す
- 天井を含めた★5の実際の割合はおよそ1.5%(`tests/run.luau` で2万回まわして確認)
- 小判は竿の段階が上がるほど多い(`Gacha.coinsFor`)

## 勾玉のもらい方(1週間でおよそ10回ぶん)
| | 勾玉 | 札 |
|---|---|---|
| はじめて遊んだ時 | | 5 |
| 毎日のログイン報酬 | 50 | 7日続けた日に1 |
| 依頼を1つ受け取る / その日の依頼を全部 | 20 / +50 | |
| 図鑑に新しい魚(釣りで) | 20 | |
| 釣り場の図鑑を全部埋めた | 300 | 1 |
| 妖怪退治の相手に初めて勝つ / 各地のぬしに初めて勝つ | 100 / 300 | 0 / 2 |
| 協力のボスに初めて勝つ / 勝った日(ボスごとに1日1回) | 300 / 30 | 1 / 0 |

数字は `Config.Gacha.Earn` を変えるだけで調整できる。

## 限定の魚の「特別感」
- 釣りでは絶対に出ない(`Config/Fish/Shrine.luau`、`spot = "shrine"`、`limited = true`)
- 体の形も限定(翻車魚・八岐大蛇・龍・海月・竜の落とし子・鳳凰魚・撞木鮫・羽衣魚)。釣れる魚には無いシルエット
- いつも虹色の光の粒・金のきらめき・光をまとう(`FishBuilder`。水槽でもほかの人に見える)
- 名前の前に「◆限定」。図鑑に「百鬼の祠」の欄ができ、「百鬼の祠でだけ授かる」と出る
- その魚だけの必殺技を覚えている(体の形の技の代わり。例: ヒノトリ「不死鳥の羽ばたき」は当てて回復)。
  **強さは釣れる魚の技と同じくらい**(威力75まで)にして、課金した人が対戦で強くなりすぎないようにしている
- 授かる時の演出: 暗転 → ★4以上なら画面が金(★5は虹)に光る → 札が順にめくれる → ★4以上の魚は1匹ずつ大きく回して、名前・「限定」の朱印・鳴き声 → まとめ(「もう一度」で続けて祈れる)
- ★5を授かると、サーバーの全員にお知らせ(表示名は Roblox がフィルタ済みの公開情報)
- 授かった魚は最初からお気に入り(🔒)。うっかり売らない・まとめて売るに入らない。魚籠がいっぱいでも入る
- 専用の鳴き声(鈴や鐘の「神さまの気配」入り)

## Roblox の決まり(有料のランダムな品)
勾玉を Robux で売るので、祠は「有料のランダムな品」にあたる。
- 確率をいつも画面に出している(祈るボタンのすぐ下)
- `PolicyService:GetPolicyInfoForPlayerAsync(player).ArePaidRandomItemsRestricted` が true の地域・年齢では、勾玉を買うボタンを出さない(遊んでためた勾玉では祈れる)。調べられなかった時も出さない
- 何が出るかは全部サーバーが決める。クライアントから来るのは「1回か10回か」だけ(それ以外は無視)
- 勾玉の商品は `Config/Products.luau` の `magatamaS / M / L`。Creator Dashboard で作って ID を入れる(0 のままなら買うボタンは出ない)

## 魚を足す
1. `tools/fish_designs.py` の `SHRINE` に1行(`signature` に必殺技の id)→ `python3 tools/fish_designs.py`
2. 必殺技を `Config/Battle.luau` の `Moves` に1行(威力75まで)
3. `Config/Gacha.luau` の `Fish` の星に id を足す
4. メッシュ(docs/ANIME_MESHES.md の「数匹だけ作り直す」)と鳴き声(docs/CRIES.md)を作り直す
