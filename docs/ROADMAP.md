## 『盗め!招き猫』からの流用について
この環境からは招き猫の Studio ファイルを読めないため、データ保存・課金・デイリー報酬・ランキング・分析は**新しく書きました**。
招き猫の仕組みに揃えたい場合は、同じ役割のモジュール(`DataService` / `MonetizationService` / `QuestService` / `LeaderboardService` / `Analytics`)を差し替えるか、招き猫側の良い部分をこちらに移植してください。サービス同士は `S`(レジストリ)経由で呼び合うので、関数名を合わせれば差し替えやすい作りです。
