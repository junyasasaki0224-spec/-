# オンライン(対戦・ボス戦・なかま)

1つのサーバーは **最大10人**(`Config/Online.luau` の `MaxPlayers`)。重くならないように、ボス戦の部屋は同時に2つまで・1部屋4人まで、対戦は1対1。
数字はすべて `Config/Online.luau` と `Config/Bosses.luau` で変えられます(コードは書かない)。

## バトル画面(妖怪退治・対戦・ボス戦で共通)

舞台は **水の中**。真横から見た水槽のような空間で、自分の相棒(左)と相手(右)がそれぞれの側を泳ぎ回る。

- 技を出すと、相手へ泳いでぶつかって戻る。補助の技はその場で跳ねて光る。かわす時は上へ身をひるがえす
- 当たり方は属性ごと: 水=泡がはじける / 火=炎の粒 / 雷=閃光と ⚡ / 土=砂けむり / 霊=紫の輪。弱点を突くと金の輪と大きな揺れ
- 倒れた子はお腹を上にして水面へ浮かんでいく。交代は前の子が泳ぎ去り、次の子が横から泳いでくる
- ボスは大きく、まわりに妖気(怒ると赤く脈打つ)
- 上: 左右に体力の札(チームの玉は属性の色)、真ん中の丸に 手番 / 対戦の残り秒 / ボス戦の残り時間
- 下: 技は **お札**(上の帯が属性、真ん中に技の名前、下に威力)。相手に効く技には「◎ 効く!」。キーボードの 1〜4 でも使える。横に「交代」「逃げる(降参・抜ける)」
- 何が起きたかは、お札の上の字幕に出る

## 画面の入り口

| 入り口 | 中身 |
| --- | --- |
| 右のメニュー ⚔ **対戦** | タブが3つ: 👹 妖怪退治(コンピューター)/ 🐲 ボス戦 / ⚔ オンライン対戦 |
| 右のメニュー 👥 **なかま** | このサーバーの人の一覧(対戦を申し込む・水槽を見に行く・友達申請)、友達を招待、ほかのサーバーで遊んでいるフレンドのところへ行く、申し込みの受け方 |
| 左の 💬 | スタンプ(決まった言葉8つ)。頭の上に出る |
| 右上のカード | 対戦の申し込み(受ける/断る・残り時間の帯)、ボス戦の仲間募集(参加) |
| 左の札 | 今やっていること(相手をさがし中・申し込み中・ボス戦の部屋で待機中)。✕ でやめる、押すとその画面が開く |

探している間・部屋で待っている間も釣りは続けられます。始まる時に釣りは自動で止まります。

## オンライン対戦(人と人)

- **ランダム対戦**: 「🎲 ランダム対戦」を押すと、チームの強さが近い人とつながる(待つほど範囲が広がる)。
  10秒たっても相手がいなければ、**ほかのサーバーの釣り人のチームの写し**(コンピューターが動かす)と戦う。60秒で見つからなければ終わり。
  点数(Elo、最初は1000)が動き、**その日の最初の勝利で ¥1,500**。
- **友達・同じサーバーの人と**: 「なかま」の ⚔ で申し込む → 相手の右上にカード → 受けると始まる。20秒で返事が無ければ取り消し。点数も小判も動かない練習試合。
  申し込みの受け方は「全員 / 友達だけ / 受け取らない」(なかま・対戦の画面で切替)。受け付けていない人・対戦中の人のボタンは最初から押せない(押してから断られない)。
- **ターン**: お互いに技を選ぶと進む。持ち時間25秒(最初は35秒)。時間が過ぎるとコンピューターが代わりに選び、3回続けて選ばないと負け。
  「相手は選び終わった!」が出るので、待たされているのか分かる。残り秒は真ん中の丸に出て、5秒を切ると音が鳴り赤くなる。
- **降参**は間違えて押さないように2回押す。降参・ゲームから抜けた人はその場で負け(抜けても点数は下がる。保存の前に負けを付ける)。
- 勝ち負けを決めるのはサーバー。画面はサーバーから届いた出来事を再生するだけ。

## ボス戦(協力)

「対戦 → 🐲 ボス戦」で **部屋を作る** か、開いている部屋に **参加**(仲間募集のカードからも入れる)。

| ボス | 魚 | Lv | おすすめ | ごほうび(1日1回) |
| --- | --- | --- | --- | --- |
| 大鯰 | 雷神鯰 | 26 | Lv18 | ¥6,000 + 光るエビ×2 |
| 海坊主 | 海坊主鱏 | 36 | Lv28 | ¥15,000 + 狐の油揚げ×2 |
| 八岐提灯 | 八岐提灯 | 48 | Lv40 | ¥40,000 + 高級エサ×3 + 称号「ボス退治の名人」 |

- 部屋は最大4人。40秒たつか4人そろうと始まる(部屋主は「始める」で早く始められる)。
- **ボスの体力は全員で1本**(人数分だけ多い)。それぞれ自分の画面で自分の相棒と戦い、与えたダメージがみんなの1本から減る。ボスの体力の札の下に仲間と与えたダメージ、真ん中の丸に残り時間。
- 体力が半分を切ると **怒る**(攻撃が上がる)。制限時間は4分。
- 自分の相棒が全員倒れたら、仲間の戦いを見守る(「抜ける」は押せる)。誰かが倒せば全員の勝ち。
- 経験値は毎回(負けても1/4)。小判とエサはボスごとに1日1回。おすすめレベルに届いていないと ⚠ で知らせる。

## なかま

- 一覧に出るのは: Roblox の表示名・顔写真・称号・図鑑の数・対戦の点数・「友達」の印・対戦中か・申し込みを受けるか。
- 🐟 **水槽**: その人の釣り小屋の前へ移動する。
- ➕ **友達申請**: Roblox の友達申請の画面を出す(友達でない人だけ)。
- 💌 **友達を招待**: Roblox の招待画面。
- **ほかのサーバーのフレンド**: 同じゲームの別のサーバーにいるフレンドの「同じサーバーへ」で移動(満員なら失敗を知らせる)。
- **スタンプ**: こんにちは / いいね / 釣れた / ありがとう / ぬしに行こう / 対戦しよう / 手伝って / またね。見る人の言語で表示。続けて送れるのは1.5秒ごと。

## 安全と個人情報

- **自由な文字は送れない**。スタンプは決まったIDだけ(サーバーが表にあるか確かめてから全員へ)。会話は Roblox 標準のチャット(Roblox が検閲する)。
- ほかのサーバーと共有するのは **チームの写し**(魚の種類・重さ・変異・レベル・点数・称号)だけ。鍵は UserId、名前は入れない。2日で自動的に消える(MemoryStore の期限)。
  対戦相手には名前ではなく「ほかのサーバーの釣り人のチーム」と出る。削除依頼の時は `DataService.eraseUser` が写しも消す。
- 公開する情報(Player の属性)は上の「一覧に出るもの」だけ。
- 通信の中身はすべてサーバーで確かめる(UserId・部屋番号は整数か、行動は move/switch/run だけ、回数制限)。勝ち負け・点数・小判・経験値はサーバーが決める。

## 作り

| ファイル | 役目 |
| --- | --- |
| `Config/Online.luau` | 人数・時間・マッチング・点数・ごほうび・スタンプ |

| `Lib/Battle.luau` | 戦いのしくみ(人と人の対戦にも対応: 相手の行動を受け取る・出来事の左右を入れ替える・見せる情報だけにする) |

| `Controllers/Online.luau` | 部屋・待ち・申し込みの状態、右上のカード、左の札 |

| `Controllers/BattleUI.luau` | 対戦の画面(3つのタブ)とバトル画面の札・お札・字幕(妖怪退治・対戦・ボス戦で共通) |

## テストと見た目の確認

```bash
lune run tests/server_sim.luau    # 申し込み・ランダム対戦・写し・時間切れ・降参・抜けた人の負け・ボス戦・スタンプ
lune run tests/client_sim.luau    # 画面: タブ・部屋・さがし中・申し込みのカード・対戦・ボス戦・なかま・スタンプ・英語

# 画面を絵にする(Studio を開かずに、文字の大きさや重なりを見る)
UI_SNAPSHOTS=build/ui lune run tests/client_sim.luau
node tools/ui/render_ui.js build/ui build/ui_png
```

`render_ui.js` は Roblox の並べ方を HTML で近似したもの(魚と顔写真は置き換えの絵)。最終確認は Studio の「テスト → サーバーとクライアント」で2〜3人。
